# TaskFlow

A responsive SaaS landing page for TaskFlow, a calm project-management workspace. It includes a dashboard preview, product features, a three-step overview, interactive monthly/yearly pricing, an FAQ, and a conversion-focused footer.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it with `npm run preview`.
